SENZO MENU - FILES

Upload index.html, style.css, and script.js to the root of your GitHub repository.
Keep all three files together in the same folder.

Then in GitHub:
1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose branch main and folder /(root), then Save.
5. Wait a minute or two for the published website link.

Note: The original menu images and pizza photos are loaded from external image URLs, so an internet connection is required.
The clickable pizza-name positions are approximate and may need adjustment after testing on the published site.
